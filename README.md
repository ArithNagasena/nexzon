# Nexzon Homepage Project

Design and build a fully responsive customer-facing ecommerce Home page for a Sri Lankan electronics retailer called Nexzon. The store sells smartphones, tablets, accessories, audio products, gaming products, and tech peripherals. The page must feel like a real active online electronics store, not a generic startup landing page or portfolio website.

Use a light UI with a clean white / very light gray base, blue as the main brand color, and a few contrasting accent colors only in promotional areas. The overall look should be modern, polished, energetic, slightly flashy, and conversion-focused, while still feeling professional and trustworthy. Use rounded soft cards, subtle shadows, clean spacing, and light animations only such as gentle hover effects, smooth transitions, soft card lift, and subtle emphasis on banners and CTAs. Keep the visual style close to a polished modern multi-brand electronics store.

Create a clean text-based logo for the brand name Nexzon in the header — the wordmark set in heavy uppercase with the `X` in the brand accent color, above a letterspaced "Electronics Shop" subline.

The homepage should include these sections in this general order:

Top promo bar above the header showing localized ecommerce trust and offer messaging such as islandwide delivery, cash on delivery, installment plans, genuine products, and warranty support.

Sticky main header with:

text logo “Nexzon”

navigation links

search bar

account icon

wishlist icon

cart icon

clean desktop navigation and mobile menu
Keep the menu simple and realistic. Suitable links can include Home, Shop, Smartphones, Tablets, Accessories, Brands, Pre-Orders, and Support.

One strong full-width hero banner focused mainly on smartphones, using multiple real modern smartphone products together in a premium campaign composition. The hero should feel like a mix of brand campaign + shopping promotion + latest smartphones showcase. Use a bold headline, supporting text, and strong CTA buttons such as Shop Now / Explore Collection / View Deals. The hero should feel exciting and premium, but still commercial. Use real product imagery from existing real-world devices, not abstract mock objects.

Trust / service highlights strip below the hero with icon-based feature points such as:

Islandwide Delivery

Secure Payments

Cash on Delivery

Easy Installments

Genuine Products

Warranty Support

Featured categories section with visually attractive rounded cards for categories such as:

Smartphones

Tablets

Accessories

Audio

Gaming
This should feel like a real store navigation section, not just decorative tiles.

Featured brands section showing major electronics brands in a clean premium way. Use real recognizable brands such as Apple, Samsung, Xiaomi, Sony, JBL, Logitech, ASUS, OnePlus or similar.

New Arrivals product section using realistic ecommerce product cards. Each card should include:

real product image

product name

brand

LKR price

optional old price

rating

wishlist button

product badge where relevant
Use realistic tech-store style cards and avoid fake placeholder design.

Mid-page promotional banner that makes the homepage feel active and campaign-driven. This can promote smartphone launches, accessories offers, installment deals, or pre-order campaigns.

Best Sellers or Trending Products section as a second product showcase, visually different enough from New Arrivals to create rhythm in the page.

Phones-focused featured section because smartphones are the main category. Create a more editorial section with stronger visual hierarchy, such as a highlighted feature banner plus selected featured phones beside or below it.

Installment / trust conversion banner emphasizing local ecommerce confidence, such as installment payment options, genuine devices, secure checkout, local support, and warranty-backed purchases.

Customer trust / testimonial section with a few clean customer review snippets or trust cards that make the store feel active and reliable.

FAQ preview section with a few ecommerce-related expandable questions such as delivery, payments, warranty, returns, and pre-orders.

Newsletter / deals signup section for latest offers, launches, and promotions.

Footer with:

text logo

short brand description

quick links

support links

contact info

social links

payment method visuals

copyright

Important design requirements:

The page must feel like a real Sri Lankan localized electronics ecommerce storefront

Show LKR pricing

Include localized trust signals such as islandwide delivery, COD, installments, warranty, and genuine products

Use real-world product images of actual electronics products

Avoid generic placeholder blocks and avoid making it look like a SaaS landing page

Make it feel active, commercial, premium, and customer-focused

Keep the layout medium-length and clean, not excessively long

Ensure desktop, tablet, and mobile responsiveness

Mobile version should remain rich and polished, but simplified appropriately for smaller screens

Use consistent design language that can be extended to the rest of the Nexzon website later

Keep animations subtle, not excessive

Maintain a professional ecommerce structure with strong hierarchy and shoppable presentation

Use clean modern typography, polished spacing, balanced visual hierarchy, and premium ecommerce composition throughout.
