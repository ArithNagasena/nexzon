## 📖 About

**Nexzon** is a customer-facing ecommerce home page for a Sri Lankan electronics retailer. It is designed to feel like a real, active online store: light and clean, blue-branded, conversion-focused and trustworthy, with rounded cards, soft shadows and subtle animations.

---

## ✨ Highlights

| | Feature | Details |
|---|---|---|
| 🇱🇰 | **Localized** | LKR pricing, islandwide delivery, cash on delivery, installment plans, genuine products, warranty support |
| 📱 | **Phone-first** | Smartphone-focused hero, featured phones and campaign banners |
| 🛍️ | **Shoppable** | Product cards with real images, brand, price, old price, rating, wishlist and badges |
| 📐 | **Responsive** | Desktop, tablet and mobile layouts, simplified but polished on small screens |
| 🎨 | **Design system** | Consistent tokens and components, ready to extend across the rest of the site |
| 🎞️ | **Subtle motion** | Gentle hover lift, smooth transitions and soft emphasis on CTAs |

## 🚀 Getting Started

**Requirements:** [Node.js](https://nodejs.org) and npm.

**1. Clone the repository**

```bash
git clone <this-repository-url>
cd <repository-name>
```

**2. Install dependencies**

```bash
npm i
```

**3. Start the dev server**

```bash
npm run dev
```
